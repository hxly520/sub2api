安全与准备

!
不要在本页或任何公开页面输入密钥

API 密钥只应在登录后的密钥管理页面创建，并填入你信任的本地客户端。不要通过聊天、邮件、截图或网页表单发送密钥。

  1. 登录控制台，在“密钥管理”中创建一枚用户密钥。
  2. 在“可用渠道”页面确认该密钥可使用的模型名称和请求类型。
  3. 根据客户端要求，手动填写 Base URL、协议类型、模型名和密钥。
  4. 先发起一次小请求验证配置，确认使用记录与客户端结果一致。
i
密钥保护建议

不要将密钥写入可公开的代码仓库、前端页面或共享文档。如怀疑泄露，请立即在控制台禁用旧密钥并创建新密钥。

CC Switch 一键导入

  1. 在本机安装并启动你信任的 CC Switch 客户端。
  2. 登录 52Token，进入“密钥管理”，在目标密钥右侧点击“导入到 CC Switch”。
  3. 如果页面要求选择客户端类型，请根据该密钥的分组协议选择。
  4. 系统打开本机 CC Switch 后，核对 Provider 名称、端点域名和模型，确认无误再完成导入。
i
安全版一键导入的范围

导入仅由用户点击触发，并由 CC Switch 显示配置预览后再确认。为保留余额识别，导入包含已固定为当前 Provider /v1/usage 的用量查询模板；模板不包含外部域名、User-Agent 探测、输入监听或动态代码加载。

文本与内容生成接口

以下是接口契约说明，不是可直接执行的命令。

协议方法与路径鉴权头最小必要字段
ResponsesPOST /v1/responsesAuthorization: Bearer <key>model、input
Chat CompletionsPOST /v1/chat/completionsAuthorization: Bearer <key>model、messages
MessagesPOST /v1/messagesx-api-key: <key>model、max_tokens、messages
Gemini ContentPOST /v1beta/models/{model}:generateContentx-goog-api-key: <key>contents

通用请求要求

  • JSON 请求必须声明 Content-Type: application/json。
  • model 必须与可用渠道页面显示的模型名完全一致。
  • 流式请求由客户端按 SSE 或对应协议消费，不要将中途断开自动视为未请求。
  • 工具调用字段应按客户端协议发送，不要同时混用多种协议的工具结构。

参考图和本地预览

  • 图片编辑请求将参考图作为 multipart 文件字段上传。
  • 画布工作台会将生成结果保存在客户端本地存储中，预览时使用本地 Blob 地址。
  • 如返回签名图片地址，域名应为 video.52token.org；请不要修改地址中的任何部分。
  • 同步生成耗时较长时请保持连接；已有任务 ID 时应继续查询，不要重复创建。

视频生成任务

当前 9 个公开视频模型共用同一套创建、查询和下载接口。固定 480p 后缀模型已下架；标准按次模型是否支持 resolution=480p 以下方限制为准。

阶段方法与端点用途
创建POST https://image.52token.org/v1/videos创建一个新的视频生成任务
查询GET https://image.52token.org/v1/videos/{task_id}查询原任务状态，不会新建任务
下载GET https://image.52token.org/v1/videos/{task_id}/content获取已完成任务的视频内容

创建任务步骤

  1. 使用 Authorization: Bearer <key> 鉴权，JSON 请求声明 Content-Type: application/json。
  2. 请求体至少包含 model 和 prompt，按模型要求增加时长、分辨率和参考素材。
  3. 建议每个业务任务设置唯一 Idempotency-Key，同一任务恢复时继续使用原值。
  4. 保存创建响应中的平台任务 ID，后续仅用该 ID 查询。

任务状态与轮询

状态含义客户端处理
creating / queued / pending / running任务仍在处理每 5-10 秒查询一次，使用同一任务 ID
completed / succeeded生成完成读取平台返回的视频地址，或请求 /content
failed / cancelled / expired任务终止停止轮询；确认需要重做后再创建新任务
!
不要因为等待时间长而重复创建

高分辨率或含参考素材的视频可能需要较长时间。创建后优先使用原任务 ID 继续查询；反复 POST 会形成多个独立生成任务。

i
参考素材地址

直接 API 调用应传公网可访问的 HTTPS 图片、视频或音频地址。本地文件路径、blob: 地址和局域网地址无法被接口读取。画布工作台会自动处理用户上传的本地素材。

比例限制

Seedance 系列

可用比例为 16:9、9:16、1:1、21:9、3:4、4:3。

Grok Video

可用比例为 1:1、16:9、9:16、4:3、3:4、3:2、2:3。

完成后的视频地址

  • 任务成功后，查询响应可能在 url、video_url或结果对象中返回平台地址。
  • 对外可见的完成地址应使用 video.52token.org，地址中不包含上游主机名。
  • 下载地址是短期签名地址，应尽快下载到客户端本地。
  • 视频播放器可按需使用 Range 分段请求；不要把地址作为永久公开链接。

错误、超时与重试

现象处理建议
401 / 403检查密钥是否有效、是否属于当前分组，以及鉴权头是否符合当前协议
402余额或密钥配额不足；图片和视频会在调用前校验可用余额
400检查模型名、必填字段、分辨率、比例和参考素材数量
429按错误响应的等待时间后重试，不要高频并发
5xx / 连接中断文本请求按客户端规则处理；图片和视频若已有任务 ID，必须先查询原任务
视频长时间运行保持 5-10 秒的查询间隔，延长总等待时间，不要重复创建
!
生图和视频不做自动重放

媒体生成可能已被服务端接受。网络超时不等于任务未创建，因此平台不会将这类请求自动重放到另一账号。有任务 ID 时使用查询接口恢复。
